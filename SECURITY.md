# Security policy

## Supported versions

mlxPDLP is currently pre-1.0. Security fixes are applied to the latest
development release.

## Reporting a vulnerability

Please use GitHub's private security-advisory reporting flow for the mlxPDLP
repository. Do not open a public issue for a vulnerability that could expose
users or data before a fix is available.

Include a minimal reproducer, affected revision, expected impact, and any
suggested mitigation. Reports will be acknowledged as soon as practical.
